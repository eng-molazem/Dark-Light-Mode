# Dark / Light Mode Toggle

**🇬🇧 [English](#-english) | 🇸🇦 [العربية](#-العربية)**

---

## 🇬🇧 English

### Overview

A simple front-end project (HTML, CSS, and JavaScript) demonstrating a dark/light theme toggle, switching the page's color scheme instantly on click.

### Tech Stack

HTML, CSS, JavaScript (vanilla, no frameworks).

### Getting Started

Open `index.html` directly in your browser, or serve the folder with any static file server.
